# 📚 SmartLib Space — ระบบจองห้องอ่านหนังสืออัจฉริยะ

เว็บแอปพลิเคชันสำหรับบริหารจัดการและจองห้องอ่านหนังสือ/ห้องประชุมกลุ่มภายในหอสมุด พัฒนาด้วย **Node.js**, **Express.js** และ **SQLite** รองรับการยืนยันตัวตนด้วย JWT, การแยกสิทธิ์ผู้ใช้งาน (User / Admin), การตรวจสอบเวลาทับซ้อน และระบบ QR Code Check-in

---

## ✨ ฟีเจอร์หลักของระบบ

1. **ระบบยืนยันตัวตน (Authentication System)**
   - ลงทะเบียนสมาชิกใหม่ (Register) และเข้าสู่ระบบ (Login) ด้วยอีเมลนักศึกษา
   - รักษาความปลอดภัยด้วย **JWT (JSON Web Token)**
2. **การจัดการและแสดงรายการห้องอ่านหนังสือ**
   - แสดงรายการห้องอ่านหนังสือพร้อมสถานที่ ความจุ และสถานะความพร้อมใช้งาน
   - ค้นหาห้องตามชื่อ/ชั้นที่ตั้ง และกรองตามขนาดความจุได้แบบเรียลไทม์
3. **การจองห้องและตรวจสอบเวลาทับซ้อน**
   - เลือกห้อง วันที่ และช่วงเวลาที่ต้องการเข้าใช้งาน (08:00 – 22:00 น.)
   - ตรวจสอบช่วงเวลาทับซ้อนอัตโนมัติ ป้องกันการจองซ้ำในห้องและเวลาเดียวกัน
4. **การแยกสิทธิ์ผู้ใช้งาน (Role-Based Access Control)**
   - **User (นักศึกษา):** จองห้อง, ดูประวัติการจอง, Check-in และยกเลิกการจองของตนเอง
   - **Admin (ผู้ดูแลระบบ):** มีสิทธิ์เพิ่มห้องอ่านหนังสือใหม่และลบห้องออกจากระบบ
5. **การยกเลิกการจอง (Cancel Booking)**
   - ผู้ใช้งานสามารถยกเลิกรายการจองที่ยังไม่ได้เข้าใช้งานได้ทันที
6. **ระบบจัดการสำหรับผู้ดูแลระบบ (Admin Dashboard)**
   - แผงควบคุมสำหรับเพิ่มห้องใหม่ (ชื่อห้อง, สถานที่, ความจุ) และลบห้องที่ไม่ใช้งาน
7. **ฟีเจอร์เพิ่มเติม**
   - **📱 QR Code Check-in:** สร้าง QR Code สำหรับยืนยันการเข้าใช้ห้อง (พร้อมเงื่อนไขยกเลิกอัตโนมัติหากไม่เช็กอินภายใน 15 นาที)
   - **📥 Export CSV:** ส่งออกประวัติการจองเป็นไฟล์ `.csv` รองรับภาษาไทย
   - **🗺️ แผนผังโซนให้บริการ:** แสดงรายละเอียดโซนต่าง ๆ (Silent Zone, Co-Working Zone, Media Zone)
   - **👤 โปรไฟล์และสถิติการใช้งาน:** สรุปยอดจองทั้งหมด รายการที่ใช้งาน และระดับสมาชิก (Standard / Gold / Platinum)
   - **💬 รีวิวและข้อเสนอแนะ & 📢 ประกาศข่าวสาร**

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** HTML5, CSS3, Vanilla JavaScript, QRCode.js
- **Backend:** Node.js, Express.js
- **Database:** SQLite (`database.db`)
- **Authentication:** JSON Web Token (JWT)

## 📁 โครงสร้างโปรเจกต์

```text
smartlib-space/
├── public/
│   ├── css/
│   │   └── style.css        # สไตล์หลักของหน้าเว็บ
│   └── index.html           # หน้าเว็บหลักและสคริปต์เชื่อมต่อ API

│   └── config/
│       └── db.js            # ตั้งค่าและสร้างฐานข้อมูล SQLite
├── database.db              # ไฟล์ฐานข้อมูล SQLite (สร้างอัตโนมัติเมื่อรันระบบ)
├── server.js                # ไฟล์หลักสำหรับรัน Express Server
├── package.json             # รายการ Dependencies ของโปรเจกต์
└── README.md                # เอกสารคู่มือโปรเจกต์
```

## 🚀 วิธีติดตั้งและรันโปรเจกต์

### 1. ติดตั้ง Dependencies
ตรวจสอบให้แน่ใจว่าติดตั้ง [Node.js](https://nodejs.org/) แล้ว จากนั้นเปิด Terminal ในโฟลเดอร์โปรเจกต์และรันคำสั่ง:

```bash
npm install
```

### 2. เริ่มการทำงานของเซิร์ฟเวอร์
```bash
node server.js
```

### 3. เข้าใช้งานผ่านเบราว์เซอร์
เปิดเบราว์เซอร์แล้วไปที่:
```text
http://localhost:3000
```

## 🧪 บัญชีสำหรับทดสอบระบบ

- **ผู้ใช้งานทั่วไป (User):** สามารถสมัครใหม่ได้ทันทีผ่านปุ่ม **ลงทะเบียนใหม่** ที่หน้าแรก
- **ผู้ดูแลระบบ (Admin):** ใช้บัญชี Admin ที่กำหนดไว้ในฐานข้อมูล (`src/config/db.js`)
